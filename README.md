# 👟 SyntaxWear — E-commerce de Tênis

Projeto de desenvolvimento de uma página de e-commerce de tênis, criado durante os estudos de desenvolvimento web. O SyntaxWear tem como objetivo praticar a construção de interfaces modernas, a organização do código e a criação de layouts responsivos.

## 📌 Sobre o projeto

O **SyntaxWear** é um projeto desenvolvido a partir de uma proposta de interface para uma loja virtual de tênis. O foco está na implementação do layout, na organização dos componentes visuais e na adaptação da página para diferentes tamanhos de tela.

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento front-end.

## ✨ Funcionalidades e recursos

- Layout de e-commerce para apresentação de produtos.
- Cabeçalho com logotipo e navegação.
- Seções para organização e exibição de categorias.
- Layout responsivo para diferentes tamanhos de tela.
- Organização dos estilos CSS para facilitar a manutenção do código.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilização, layouts e responsividade.
- **Flexbox** — alinhamento e distribuição dos elementos.
- **CSS Grid** — organização de elementos em grades.
- **Media Queries** — adaptação do layout a diferentes resoluções.
- **Git e GitHub** — versionamento e hospedagem do código.

## 🎯 Objetivos de aprendizado

- Praticar a estruturação de páginas com HTML semântico.
- Aprimorar o uso de Flexbox e CSS Grid.
- Desenvolver layouts responsivos.
- Trabalhar com espaçamentos, alinhamentos e hierarquia visual.
- Melhorar a organização e a manutenção do código CSS.
- Utilizar o Git e o GitHub para acompanhar a evolução do projeto.
